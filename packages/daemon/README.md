# @axon-assistant/core

Ядро [Axon](https://github.com/bigtaed-sys/axon) — персонального AI-агента,
который живёт на вашей машине, а не в чужом облаке.

Ядро владеет всем: историей, памятью, инструментами, контекстом, вызовами
моделей. Приложения (десктоп, Telegram) подключаются к нему и синхронизируются
через журнал событий. Сколько бы устройств ни было подключено, контекст один,
кэш промпта один, и расход токенов не умножается на число экранов.

## Установка

Node 22.5+. Нативных модулей нет, компилятор не нужен.

```bash
npm install -g @axon-assistant/core
axon start                      # слушает 127.0.0.1:8787
axon start --host 0.0.0.0       # ещё и для устройств из сети
```

При первом запуске ядро печатает код для подключения первого устройства и
кладёт его в `bootstrap.code` рядом с данными — код сгорает после первого
использования.

```bash
axon status                                     # запущено ли и где
axon secret set provider.anthropic.apiKey sk-…  # ключ провайдера
axon devices                                    # подключённые устройства
axon plugin catalog                             # что можно поставить
axon backup create                              # архив с базой и блобами
axon stop
```

Папка данных задаётся переменной `AXON_DATA_DIR`; по умолчанию — стандартная
папка приложений вашей ОС. Внутри лежит всё: база, блобы и ключ шифрования
секретов. Переносится копированием.

## Что уходит наружу

К провайдеру модели — то, что вы видите в разборе контекста. Есть ровно одно
исключение, и оно по вашему действию: открытая вкладка «Каталог» в плагинах
тянет список из публичного репозитория, без каких-либо сведений о вас. Само по
себе ядро в сеть не ходит: обновлений, телеметрии и «анонимной статистики» нет.

## Плагины

Свои инструменты, скиллы, работа по расписанию и провайдеры моделей пишутся на
[@axon-assistant/plugin-sdk](https://www.npmjs.com/package/@axon-assistant/plugin-sdk).
Заготовка — `axon plugin new мой-плагин`. Чужие MCP-серверы подключаются
конфигурацией из их README, без обёрток.
