# @axon-assistant/plugin-sdk

Типы для написания плагинов [Axon](https://github.com/bigtaed/axon).

Пакет нужен только редактору. В рантайме плагину импортировать из него нечего:
`api` приезжает аргументом в `activate`. Плагин без единой зависимости — папка,
которую можно склонировать и запустить, а не проект, который надо сначала собрать.

```bash
npm i -D @axon-assistant/plugin-sdk
```

## Из чего состоит плагин

```
my-plugin/
  axon.plugin.json   манифест — единственный обязательный файл
  index.js           точка входа, если у плагина есть код
  skills/*.md        инструкции текстом, если они есть
```

Плагин **без кода** — законная и частая вещь: манифест из десяти строк,
поднимающий чужой MCP-сервер.

## Манифест

```json
{
  "id": "weather",
  "name": "Погода",
  "description": "Прогноз для города пользователя",
  "version": "1.0.0",
  "api": 1,
  "main": "./index.js",
  "permissions": ["net"],
  "settings": [
    { "key": "apiKey", "label": "Ключ OpenWeather", "type": "secret", "required": true },
    { "key": "city", "label": "Город", "type": "text", "default": "Варшава" }
  ],
  "skills": "./skills",
  "mcpServers": {},
  "jobs": [{ "name": "утренняя-сводка", "everySeconds": 3600 }]
}
```

| Поле | Смысл |
| --- | --- |
| `id` | Слаг. Им префиксуются инструменты: `search` → `weather_search` |
| `api` | Версия API плагинов. Сейчас `1` |
| `main` | Точка входа. Нет — плагин без кода |
| `permissions` | `fs`, `net`, `shell`, `secrets`, `journal`. Показываются пользователю до установки |
| `settings` | Форма, которую нарисует интерфейс. `secret` хранится шифрованным |
| `skills` | Папка с `*.md` |
| `mcpServers` | Имя → транспорт. `${ключ}` подставляется из настроек при запуске |
| `jobs` | Задачи по расписанию. Обработчик вешается через `api.jobs.on` |

## Код

```js
export async function activate(api) {
  await api.tools.register({
    name: 'forecast',
    title: 'Прогноз погоды',
    description:
      'Узнать погоду в городе. Вызывай, когда спрашивают про погоду, ' +
      'дождь, температуру или что надеть.',
    tier: 'sensitive',
    parameters: {
      type: 'object',
      properties: { city: { type: 'string', description: 'Город' } },
      required: ['city'],
    },
    async execute({ city }) {
      const key = api.settings.get('apiKey');
      const res = await fetch(`https://api.openweathermap.org/…&q=${city}&appid=${key}`);
      return JSON.stringify(await res.json());
    },
  });
}

export function deactivate() {}
```

`execute` возвращает строку или `{ text, mime }`.

## Что даёт `api`

| | |
| --- | --- |
| `api.tools.register/unregister` | свои инструменты |
| `api.context.contribute(name, stability, fn)` | абзац в промпт |
| `api.skills.add` | скилл на лету (обычно они просто файлы в `skills/`) |
| `api.providers.register` | свой провайдер модели |
| `api.jobs.on(name, fn)` | обработчик задачи из манифеста |
| `api.journal.on(fn)` | события ядра (нужно право `journal`) |
| `api.settings.get/set/onChange` | настройки плагина |
| `api.memory.facts/remember` | долговременная память пользователя |
| `api.blobs.write` | большой вывод мимо контекста модели |
| `api.log.*` | в логи плагина, видные в интерфейсе |
| `api.dir` / `api.dataDir` | своя папка и папка для своих данных |

## Как не сжечь бюджет пользователя

Это главное, ради чего Axon вообще существует, и плагин может всё испортить.

**Редкий инструмент помечайте `deferred: true`.** Тогда его схема не грузится в
контекст, пока модель сама не спросит. Пять инструментов с подробными схемами —
это несколько тысяч токенов в *каждом* запросе.

**Длинный вывод кладите в `api.blobs.write`,** а модели отдавайте краткую
сводку. Всё, что вернул инструмент, остаётся в истории разговора и
переотправляется каждый ход.

**`stability` у вклада в контекст выбирайте честно.** `stable` уходит в
кэшируемый префикс промпта, `volatile` — в хвост. Изменчивый текст (время,
курс, погода), положенный в `stable`, обнуляет кэш промпта на каждом ходу.
Ошибка не видна глазом и стоит десятикратной цены запроса.

**Длинные инструкции — это скилл, а не описание инструмента.** У скилла в
контексте постоянно висит одна строка; тело модель читает сама, когда задача
под него подходит.

## Как поставить свой плагин

```bash
axon plugin link ./my-plugin    # подключить папку как есть
axon plugin reload my-plugin    # подхватить правки
axon plugin logs my-plugin      # что он печатает
```

`link` есть только в CLI: это режим разработки. Пользователи ставят плагины из
каталога или из git-репозитория.

## Как это работает внутри

Каждый плагин запускается **отдельным процессом**. Бесконечный цикл, утечка
памяти или `process.exit()` внутри плагина убивают только его: ядро видит
падение, снимает регистрацию его инструментов и продолжает работать.

Обратная сторона — всё общение с ядром асинхронное и проходит через
сериализуемые сообщения. Возвращать из `execute` можно только то, что
переживёт `JSON.stringify`.

Песочницы при этом нет: процесс работает с правами пользователя. `permissions`
в манифесте — это информированное согласие, а не ограничение. Чужой
непроверенный код правильнее подключать как MCP-сервер.
