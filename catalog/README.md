# Каталог плагинов Axon

Этот файл ядро тянет по сети, когда человек открывает установку плагинов.
Добавить плагин в каталог — значит поправить `catalog.json`, а не выпускать
новую версию ядра.

## Куда его класть

В отдельный **публичный** репозиторий: `raw.githubusercontent.com` отдаёт файлы
приватных репозиториев только с токеном, а ядру его взять неоткуда — да и не
должно.

Адрес по умолчанию:

```
https://raw.githubusercontent.com/bigtaed-sys/axon-catalog/main/catalog.json
```

Меняется настройкой `plugins.catalogUrl` — например, на свой форк или на
внутренний адрес в организации.

## Что в нём

```json
{
  "version": 1,
  "updatedAt": "2026-08-23",
  "entries": [ … ]
}
```

Голый массив тоже принимается: ядро понимает и `[...]`, и `{ "entries": [...] }`.

Каждая запись проверяется по схеме `zCatalogEntry` **по отдельности**. Битая
выбрасывается, остальные остаются: одна опечатка не должна оставлять человека
без всего раздела. Из каталога ставят программы — доверять ему на слово нельзя
тем более.

## Что сюда попадает

Только то, что действительно существует и ставится без OAuth-танцев. Всё, что
требует браузерного входа, честнее ставить руками, чем делать вид, что установка
происходит в один клик.
